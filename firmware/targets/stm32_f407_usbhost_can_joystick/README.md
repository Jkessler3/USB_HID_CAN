# stm32_f407_usbhost_can_joystick

Active target for the standalone translator box:

- USB Thrustmaster joystick -> STM32 USB Host HID -> CAN1 -> RC controller

## Current Baseline

- USB Host HID stack generated by CubeMX (`USB_HOST/*`)
- CAN1 enabled and RX interrupt path present in `Core/Src/main.c` and MSP/IT files
- USB host process loop is active (`MX_USB_HOST_Process()` in main loop)

## Direction

- Keep USB in host mode (no USB device middleware)
- Keep CAN1 as output transport for mapped joystick commands
- Use shared modules:
  - `firmware/shared/usb_host_hid`
  - `firmware/shared/mapping`
- Target-level non-generated glue:
  - `App/joystick_translator_app.[ch]`
